Документация

Все возможности платформы и инструкции

📋 Ознакомление

Scoreboard App — платформа для управления спортивными трансляциями в реальном времени.

Основные возможности:

  • Создание и управление командами (название, город, цвета, эмблема)
  • Создание матчей с выбором команд и шаблонов
  • Управление таймером матча (старт, пауза, стоп, добавленное время)
  • Счёт матча (голы с подсветкой и анимацией)
  • Статистика в реальном времени (удары, угловые, фолы, владение мячом и др.)
  • Состав команд и замена игроков
  • Серия пенальти (интерактивный ввод)
  • Оверлей для OBS (счёт, таймер, события, статистика)
  • Превью матча и интро перед трансляцией
  • Синхронизация в реальном времени через Ably
  • Система аккаунтов и подписок (trial, базовый, стандартный, премиум)
  • Админ-панель для управления пользователями

Форматы спорта: футбол 11×11, 8+1, мини-футбол, футзал, пляжный футбол, хоккей, баскетбол, волейбол.

👥 Как добавить команду

  1. В левом меню нажмите «Команды»
  2. Нажмите кнопку «+ Создать»
  3. Заполните:
    • Название команды (например, «ФК Минск»)
    • Город
    • Эмблема — нажмите на иконку и загрузите изображение или выберите из папки
    • Цвета команды — основной, дополнительный, текст
  4. Нажмите «Сохранить команду»

💡 Команды можно также импортировать через JSON (кнопка «Импорт» на странице Команд).

⚽ Как создать матч

  1. Нажмите кнопку «Начать матч» в боковом меню или «+ Создать матч» на главной
  2. Выберите Хозяев и Гостей из списка созданных команд
  3. Выберите шаблон или создайте новый (на странице «Шаблоны»)
  4. Укажите название матча
  5. Нажмите «Создать матч»
🎮 Управление матчем в трансляции:
• Таймер: Старт / Пауза / Стоп / Добавить время
• Счёт: +/- для каждой команды (гол → анимация в OBS)
• События: Жёлтая карточка, Красная карточка, Замена, Гол (текст баджа)
• Статистика: Вкладка «Статистика» — редактирование в реальном времени
• Составы: Вкладка «Состав» — выберите игроков и покажите на экране
• Пенальти: Вкладка «Пенальти» — пошаговый ввод результатов

🖥️ Как добавить оверлей в OBS

  1. Откройте OBS Studio
  2. В источнике нажмите «+» → Browser (Браузер)
  3. В поле URL введите: http://ВАШ_IP:3000/widget.html?match=ID_МАТЧА
  4. Где ID_МАТЧА — ID матча из таблицы на странице «Матчи» (колонка слева)
  5. Ширина: 1920, Высота: 180 (или под ваш размер)
  6. Включите «Управление источником через OBS» (если нужно для прозрачности)
  7. Нажмите OK
✅ Что отображается в оверлее:
• Счёт матча и таймер слева внизу
• Названия команд с логотипами и цветами
• События (гол, карточки, замены) — всплывают с анимацией
• Серия пенальти (если активна)
• Статистика и превью матча (через кнопки в разделе «Графика»)
💡 Советы:
• Для прозрачного фона в OBS: галочка «Управление источником через OBS» → настройка прозрачности
• Расположите оверлей поверх видео с помощью «Порядок расположения»
• Можно добавить несколько оверлеев для разных матчей
